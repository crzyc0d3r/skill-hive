## Install graphify (repeat for later phases)

The graph-automation skill invokes a `graphify` executable with `extract`, `cluster-only`, `explain`, `affected`, `query`, `reflect`, and `save-result`. That executable is the console script from the PyPI package `graphifyy` 0.9.90 (import name `graphify`). Do not `pip install graphify`: that name is an unrelated 2015 jQuery graph helper. Do not `npm install graphify` for the same reason. `@sentropic/graphify` and `@sentropic/engram` are later renames of this tool; this run used the PyPI package whose CLI still matches the skill runbook.

From the repo root, with Python 3.12:

```bash
python3 -m pip install --user 'graphifyy==0.9.90'
export PATH="$HOME/.local/bin:$PATH"
graphify extract /workspace --code-only --force
graphify cluster-only /workspace --no-viz --no-label
graphify reflect --if-stale --graph graphify-out/graph.json --memory-dir graphify-out/memory --out graphify-out/reflections/LESSONS.md
python3 .claude/skills/graph-automation/scripts/graph_context.py summary --graph graphify-out/graph.json
python3 .claude/skills/graph-automation/scripts/graph_context.py focus --graph graphify-out/graph.json --query "validate_skill publish_draft VersionStore render_agent_file AppShell LibraryView SettingsView"
```

Verified on 2026-10-14: `graphify extract /workspace --code-only --force` wrote `graphify-out/graph.json` (2709 nodes, 5524 edges). `graphify cluster-only /workspace --no-viz --no-label` produced 172 communities and `graphify-out/GRAPH_REPORT.md`. `graphify explain validate_skill --graph graphify-out/graph.json` resolves to `crates/hive-core/src/authoring/validator.rs`. `--code-only` skips docs, so `PLAN.md` is not in the map. graphify also skipped `src/styles/tokens.css` with its own sensitive-file filter. The AST cache under `graphify-out/cache/` is gitignored and is rebuilt by extract.

The split uses that map. Communities 1, 7, 8, 9, 10, and 63 all contain `crates/hive-core/src/authoring/tests.rs`, so they are one code node (`n1_authoring`) which also reads community 76 (`fixtures/authoring/quick_validate.py`). Communities 31 (`AppShell.tsx`), 46 (Library and Dashboard), 60 (`App.tsx` and routes), and 64 (Settings and i18n) share `App.tsx`, so they are `n2_editors`. Shadcn component communities and `automations/skill-hive-p0/sources/reference/skill_store.rs` showed up in `focus` only because the query tokens were generic or because the file is a vendored copy. They are not nodes.
