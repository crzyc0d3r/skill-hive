## Install graphify (repeat for later phases)

The graph-automation skill invokes a `graphify` executable. That executable is the console script from the PyPI package `graphifyy` 0.9.90 (import name `graphify`). Do not `pip install graphify`.

```bash
python3 -m pip install --user 'graphifyy==0.9.90'
export PATH="$HOME/.local/bin:$PATH"
graphify extract . --code-only --force
graphify cluster-only . --no-viz --no-label
graphify reflect --if-stale --graph graphify-out/graph.json --memory-dir graphify-out/memory --out graphify-out/reflections/LESSONS.md
python3 .claude/skills/graph-automation/scripts/graph_context.py summary --graph graphify-out/graph.json
python3 .claude/skills/graph-automation/scripts/graph_context.py focus --graph graphify-out/graph.json --query "ChatProvider run_migrations store_credential sanitize is_path_safe AppShell"
```
