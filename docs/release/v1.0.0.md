# Skill Hive 1.0.0

Skill Hive 1.0.0 is the first release that can be signed, notarized, and updated in place. Unsigned builds still complete when the signing secrets are absent.

## Install

- macOS: the `.dmg` for Apple silicon or Intel. `brew install --cask skill-hive` uses the cask in `packaging/homebrew` after the release is published.
- Windows: the `.msi` or `-setup.exe`. `winget install SkillHive` uses the manifest in `packaging/winget` after it is submitted.
- Linux: `.deb` and `.rpm` declare WebKitGTK 4.1 and Ayatana AppIndicator. The AppImage is the update channel.

## Updates

Check for Updates notifies. Install Update on macOS and Windows asks you to restart. Linux shows Download. A tampered `latest.json` signature is rejected. The updater key is Skill Hive's own minisign key.

## Notes

Signing and notarization run in GitHub Actions only when the secrets in `docs/release/secrets.md` are present. This draft is unsigned until those secrets are added and a new tag is pushed.
